# 关于 Samuel 的个人门户

这是 Samuel 的个人门户，AI 对话是主要入口。访问者无需逐页浏览，可以直接询问主人公开分享的内容；助手会检索相关资料、组织回答，并尽量标注来源。需要查看原文时，可以从回答中的引用进入。如果偏好传统页面，也可以浏览 Classic Portal。

## 如何使用

1. 在输入框直接提出感兴趣的问题，不必先知道资料放在哪里。
2. 不确定从哪里开始时，可以选择首页的推荐问题。
3. 查看回答附带的引用，打开原始资料核查重要信息。
4. 继续追问具体细节，对话会保留在当前浏览器中。

## 回答边界

助手只应依据 `content/references` 中提供的公开资料回答事实性问题。资料没有覆盖时，应明确说明“现有资料中没有支持该结论的内容”，而不是猜测。助手不是 Samuel 本人，不应以 Samuel 的身份声称个人经历或观点。

引用用于帮助访问者核查原始资料。引用存在并不自动证明回答正确，重要信息仍应打开来源核对。

## 内容维护

把新的公开 Markdown 资料放进 `content/references`。文件顶部可以包含 title、url、publishedAt、summary 和 tags。正文建议按主题使用二级标题，便于检索和定位。

## 隐私

对话历史只保存在访问者自己的浏览器中，主人不会通过这些历史记录建立访客档案。新的提问会发送到服务器，并交给配置的模型服务生成回答。请勿输入密码、证件号码或联系方式等敏感信息。
