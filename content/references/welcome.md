# 关于这个参考问答门户

这个门户只提供一个 AI 对话框。访问者可以针对主人公开的 reference 提问，助手根据检索到的资料组织回答，并尽量标注来源。

## 回答边界

助手只应依据 `content/references` 中提供的公开资料回答事实性问题。资料没有覆盖时，应明确说明“现有资料中没有支持该结论的内容”，而不是猜测。

引用用于帮助访问者核查原始资料。引用存在并不自动证明回答正确，重要信息仍应打开来源核对。

## 如何使用

把新的公开 Markdown 资料放进 `content/references`。文件顶部可以包含 title、url、publishedAt、summary 和 tags。正文建议按主题使用二级标题，便于检索和定位。

## 隐私

对话历史只保存在访问者自己的浏览器中，主人不会通过这些历史记录建立访客档案。新的提问会发送到服务器，并交给配置的模型服务生成回答。
